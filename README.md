# 雪國十三日 · 北海道 2027

2027/1/7–1/19 北海道親子滑雪行程網站（小樽 Kiroro → 富良野 → 札幌）。

- 每日行程、車程（一般／下雪）、日出日落
- 地圖：MapLibre + OpenFreeMap，雪場、住宿、餐廳、溫泉、醫院
- 從住宿或目前位置（GPS）計算到各雪場的車程（OSRM）
- 即時天氣：Open-Meteo（含 Kiroro、富良野山頂）
- 雪場票價、兒童規定、雪具店；吃喝；出發前待辦

純靜態網站，直接放 GitHub Pages：Settings → Pages → Source 選 `main` / root。
資料在 `data/trip.js`；路線在 `data/routes.geojson`。不含任何個資。
